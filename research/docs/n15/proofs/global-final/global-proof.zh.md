# 对任意 15 圆心的全局下界

α 精确定义为本目录 `source/core/system15.py` 的 148 元整数系统在 `source/core/root15.json` 指定有理根盒中的唯一根的半径平方坐标 t 的正平方根。根的存在性、唯一性与 α>0 使用根接受器的压缩映射证书；它不是由十进制近似或未取得的最小多项式定义的。

目标命题是

```math
\forall C\in(\mathbb R^2)^{15},\qquad R_D(C)\ge\alpha.
```

书面归约见[反例归约](reduction.zh.md)，枚举及接受器审查见研究记录 `enumeration-review.zh.md`，完整几何与分析证明见[上游证明阅读版](source/PROOF-reading.zh.md)。下面说明实际有限检查满足哪些充分条件，以及怎样闭合量词。

## 1. 有限检查与证明命题的对应

五族的新生成面表必须逐代表满足圆盘复形判据。独立审计器的群码两两不同，给出两两互异的 G=D_B×S_I 轨道。每个轨道的标号质量是 |G|/|Stab|；其和等于独立根面递推 T(B,I)，从而五族所有轨道均出现。该论证不把生成器的搜索终止、预计轨道总数或成功字段当作完整性证据。

在任一辅助杆实现中，按圆周次序旋转固定 q_0=(1,0)，必要时反射整个实现以匹配选定代表的边界方向。设 q_i=(cos2πu_i,sin2πu_i)，0=u_0≤…≤u_(B−1)≤1。每个边界胞腔只有一条短弧，其角隙上限为 asinρ/π。精确接受器核验 U>α、U<sin(πA)、2U<sin(πC)、U<sin(π/9)、U<1/2，其中 U=0.318142930859264、A=10306/100000、C=21954/100000。因此每个隙≤A；四杆路径的弦长≤4ρ<4U，提供来源 §6 的连续隙和必要条件。

距离或 Farkas 排除都只使用必要条件：直接距离矛盾不可能有实现；非负整数权重使每个隙的总系数≥1，而加权右端<1，与所有隙之和为 1 矛盾。度量接受器重读每个新生成的代表，重建签名并核验权重；它同时产生全部残余面表，精确对照固定 residuals。分类没有漏掉一个新生成的代表。

## 2. 森林为什么排除整个连续域

根角域覆盖所有满足上述必要差分条件的实现。Floyd–Warshall 闭包与盒收缩不删除可行点。SPLIT 的两闭子盒覆盖父盒；所有节点可达且只访问一次，杜绝缺失分支、未访问附加节点和循环。EMPTY 叶必须由必要条件证明为空。

对一个 DUAL 叶，给每条定向杆 e=uv 有理力 f_e，自由节点净力为零，锚点净力为 F_i=λ_i a_i−d_i、λ_i≥0，固定锚点净力为其它之负和。整盒半平面 a_i·q_i≥b_i 与散度恒等式给出

```math
\begin{aligned}
\sum_{i>0}\bigl[\lambda_i(b_i-a_{ix})\\
&\qquad{}-(|d_i|-d_{ix})\bigr]\\
&\le\sum_e f_e\cdot(z_u-z_v)\\
&\le\rho\sum_e|f_e|.
\end{aligned}
```

接受器向下界定左端、向上界定正范数和，全部使用整数或 Fraction。只有二者比值严格大于 U>α 时才排除。不存在“只检查盒中心”的接受规则，也不依赖发现力向量的浮点优化器是否收敛。重合自由节点同样满足恒等式。

非候选记录集合必须恰为残余面表集合删除唯一候选。对候选，通过具体二面体边界映射与内部置换逐面核验同构，再检查 61 杆局部图在完整候选图中的嵌入。

## 3. 候选 LOCAL 叶为什么足够

候选根的 61 个杆权 w_e>0，10 个径向乘子 −1/80<μ_i<0。来源 §8 定义候选几何 Jacobian A_*、加权 Laplacian M、锚点投影 P_A 和 W=diag(w_e²,ν²)，ν=1/80。整数矩阵乘法、可逆有理上三角合同与严格对角占优，结合显式根到有理矩阵的误差界，证明

```math
H=M+300A_*^TWA_*-\frac9{5000}P_A\succ0.
```

对同图任意杆长≤α 的实现，令 d=y−y_*，a²=d^TP_A d。平方约束精确展开及驻定恒等式给出

```math
d^TMd\le0,\qquad d^TA_*^TWA_*d\le2\nu^2a^4.
```

若整盒锚点距离 a≤13/100，则

```math
\begin{gathered}
d^THd\le600\nu^2a^4-\frac9{5000}a^2\le0,\\
\frac9{5000}-600\nu^2(13/100)^2=\frac{69}{320000}>0.
\end{gathered}
```

与 H 正定相矛盾，除非 d=0。因此局部叶中的活跃图必须等于候选，不要求自由圆心或公共点预先接近候选。候选中活跃杆的长度恰为 α，不可能全部≤ρ<α。LOCAL 接受器用精确三角区间与根盒界定每个整弧的距离最大值，证明整个角盒 a<13/100；没有从局部根唯一性偷换为整个连续候选域唯一性。

## 4. 最后量词闭合

若存在原题中任意 C 使 R_D(C)<α，`reduction.zh.md` 给出某个 ρ<α 的五族辅助杆实现，处理了盘外圆心、重合、冗余、删盘后的退化和不足 15 点的补点。完整枚举包含它的组合轨道。度量排除者立即矛盾；剩余非候选者落在完整森林的某叶，EMPTY 或 DUAL 都不可能；唯一候选者落在其完整树的某叶，DUAL 或 LOCAL 也都不可能。故不存在严格反例，得到 R_D(C)≥α 对所有 C 成立。

同根覆盖接受器核验的 39 个三角形与 11 个圆弓，配合来源 §3 的公共点、双圆三角形、拓扑圆盘绕数和圆弓引理，提供 R_D(C_*)≤α。因此在上述全部接受条件实际通过时，也有 r_D(15)=α。
