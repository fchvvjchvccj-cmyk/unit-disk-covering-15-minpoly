## 2. 实际成立的是二阶传递

记 `a=c2`、`c=c3`、`b=c12`，`kappa=1-r^2`。两个相邻活跃面的公共点记为 `p,p'`，相邻边界接触点记为 `q,q'`。在目标非退化方向上，互补交点满足

```math
\begin{gathered}
q+p=a+c,\\
q+q'=\frac{|c|^2+\kappa}{|c|^2}c,\\
p+p'=c+b.
\end{gathered}
```

于是后一个圆心满足

```math
\boxed{c_4=b-a+\kappa\frac{c}{|c|^2}.}
```

接受器验证通用有理恒等式，并在原根整盒中严格分离两组公共点、边界点及圆心，支持互补交点选择。在复坐标中，这可写为 `z_next=b-z_prev+kappa/conj(z)`。若 `b-z_prev` 固定，它是反分式线性变换；实际传递中 `z_prev` 也变化，所以不能把整链直接当作固定系数的 Möbius 矩阵复合。

更关键的是原面表中 `(2,3,12)`、`(3,4,12)` 活跃，下一面 `(4,5,12)` 不活跃。令

```math
\begin{aligned}
T(A,B,C)&=|A-B|^2|B-C|^2|C-A|^2\\
&\quad{}-4r^2[B-A,C-A]^2.
\end{aligned}
```

本轮整盒有理区间证明

```math
-0.001042\lt T(c_4,c_5,c_{12})<-0.001041.
```

错误地继续传递得到的圆心与实际 `c5` 的距离平方严格位于 `(0.000544,0.000545)`。因此把下一面补成等式会丢掉原目标。本轮将这条延长路线排除，保留有效的局部有理传递。

## 3. 左右端口的显式分量选择

以下 `a=(x,y)=c2`，`U=(u,0)=c11`，`b=(v,w)=c12`，`P=(px,py)` 为三角形 `(a,U,b)` 的外心。原活跃面保证其半径为 `r`。令

```math
\mathrm{circle}=y^2-2p_y y+x^2-2p_xx+2up_x-u^2,
```

```math
G=(2x-p_x)^2+p_y^2-1,
```

```math
C_1=p_xu-p_xx-p_yy-u^2+ux,
```

```math
\begin{aligned}
C_2&=-p_x^2+4p_xu-4p_xx\\
&\quad{}-p_y^2-2u^2+2ux+1.
\end{aligned}
```

[恒等式核验脚本](../../../../n15/algebra/contact-transfer-20261024/identities.py)直接读取原轴系统的 `H10` 整数系数，以 `r^2=(px-u)^2+py^2` 代换，再对 `circle` 作一元多项式除法，逐项核验

```math
\boxed{H_{10}=Q\,\mathrm{circle}+2GC_1C_2.}
```

实际 `Q` 的全部整数系数保存在正式验证报告中。原盒上 `C1` 位于 `(-0.145,-0.143)`，`C2` 位于 `(0.528,0.529)`，故目标必满足 `G=0`。这给出后述第二层二次关系，未使用残差小来选择分量。

右端令 `Z=2*c6x-1-r`、`c5=(d,e)`，`edge=(v-Z)^2+w^2`。定义两个整系数圆方程

```math
\begin{aligned}
C_+&=w[d^2+e^2-(Z+2v-u)d\\
&\qquad{}+Z(2v-u)]\\
&\quad{}-[w^2-(v-Z)(v-u)]e,
\end{aligned}
```

```math
\begin{aligned}
C_-&=w[d^2+e^2-(Z+u)d+Zu]\\
&\quad{}-[w^2+(v-Z)(v-u)]e.
\end{aligned}
```

原轴第九行是 `H9=((u-v)^2+w^2)*edge-4*r^2*w^2`。独立整数展开证明

```math
\boxed{w^2T(c_5,b,(Z,0))=\mathrm{edge}\,C_+C_-+H_9\,\mathrm{cross}^2.}
```

原盒中 `C-` 位于 `(-0.148,-0.146)`，`w`、`edge` 非零，故目标选择 `C+=0`。这一分量选择现在有直接的端口几何证明。

## 4. 交点叉积基和共享根

记 `dx=v-u`、`L=dx^2+w^2`，`aa=2(px-u)`、`bb=2py`。公共点的两个圆方程给出

```math
aa^2+bb^2=4r^2,\qquad dx\,aa+w\,bb=L.
```

令 `t=dx*bb-w*aa`。通用整数恒等式给出

```math
\begin{gathered}
t^2=L(4r^2-L),\\
aa=dx-\frac{wt}{L},\\
bb=w+\frac{dx\,t}{L}.
\end{gathered}
```

这避免以半角参数引入 `1+s^2` 分母。另一个恒等式为

```math
\begin{aligned}
&L(dx-aa)^2-w^2(4r^2-L)\\
&\quad{}=w^2(aa^2+bb^2-4r^2)\\
&\qquad{}+(dx\,aa+w\,bb-L)\\
&\qquad\quad{}\cdot(dx\,aa-w\,bb-L).
\end{aligned}
```

结合原 `H9`，右端二次根精确分为 `R-(dx-aa)` 和 `R+(dx-aa)`，其中 `R=2*c6x-1-r-v`。原盒中后一因子位于 `(0.688,0.689)`，故

```math
c6x=(1+r+v+dx-aa)/2.
```

这是左右交点共享二次根的直接证明；不能把两边分别计为独立扩张。

## 5. 新八变量本原系统

变量顺序固定为

```math
(t,z,h,y,u,v,w,r).
```

四层载体为

```math
g_0=t^2-L(4r^2-L)=0,
```

```math
\begin{gathered}
p_x=u+aa/2,\quad p_y=bb/2,\\
g_1=z^2+p_y^2-1=0,
\end{gathered}
```

```math
\begin{gathered}
a_x=(p_x+z)/2,\\
g_2=(h-p_y)^2+(a_x-p_x)^2-r^2=0,
\end{gathered}
```

```math
\begin{gathered}
x_6=(1+r+v+dx-aa)/2,\\
g_3=(x_6-1)^2+y^2-r^2=0.
\end{gathered}
```

四条关系在参数环 `Q[u,v,w,r,1/(2L)]` 上逐层首一二次，因此它们本身定义秩 `2^4=16` 的有限自由载体。后续电路还需局部化载体中的其他元素；不由目标处非零推断这些元素在整个参数纤维均为单位，也不宣称局部化后自动保持自由秩十六。此处的秩不是临界点总数或半径代数次数。

以 `a=(ax,h)` 重建

```math
\begin{aligned}
c_3=\biggl(&v+\frac{(|a|^2+1-r^2)a_x}{|a|^2}-z-p_x,\\
&w+\frac{(|a|^2+1-r^2)h}{|a|^2}-2p_y\biggr),
\end{aligned}
```

```math
c_4=b-a+(1-r^2)c_3/|c_3|^2.
```

右端 `c5=(d,e)` 在两个圆方程上。令 `beta=r^2-1`、`Sx=2*x6+beta`，

```math
a_c=2-4x_6^2/Sx,\quad e_c=-4x_6y/Sx,
```

```math
\begin{aligned}
b_c&=-(Z+2v-u),\\
b_e&=-[w^2-(v-Z)(v-u)]/w,\\
b_0&=Z(2v-u).
\end{aligned}
```

两圆相减给出

```math
\begin{aligned}
e&=e_0+e_1d,\\
e_0&=-(b_0+\beta)/(b_e-e_c),\\
e_1&=-(b_c-a_c)/(b_e-e_c).
\end{aligned}
```

代回第一圆得 `g=A*d^2+B*d+C=0`，其中

```math
\begin{aligned}
A&=1+e_1^2,\\
B&=2e_0e_1+a_c+e_ce_1,\\
C&=e_0^2+e_ce_0-\beta.
\end{aligned}
```

最后的边界闭环记为 `H=B(c4,c5;r)`。项目已有的本原因式分解，在单位圆公共点 `q` 及其圆方程上给出 `H=f*Q`，其中

```math
f=|c_4|^2+1-r^2-2c_4\cdot q.
```

先剥离 `f`，再将 `Q` 模 `g` 化为 `J0+J1*d`。新闭环为

```math
\boxed{F=A J_0^2-BJ_0J_1+CJ_1^2.}
```

`model.py` 完整列明 `J0,J1` 的有理电路。`A,J1,2Ad+B,f` 在目标处均为单位，故 `d=-J0/J1` 唯一恢复原点。在共同零集上，独立微分恒等式给出

```math
\begin{aligned}
dF&=-J_1(2Ad+B)dQ\\
&=-\frac{J_1(2Ad+B)}f\,dH.
\end{aligned}
```

因此半径临界性精确保留。四层载体上按隐函数规则取全导数，最终八式为

```math
\boxed{\begin{gathered}
g_0=g_1=g_2=g_3=F=0,\\
\delta_uF=\delta_vF=\delta_wF=0.
\end{gathered}}
```

目标使用 `r>0`、全部电路分母非零、四个二次根简单，以及 `A,J1,2Ad+B,f,delta_rF` 非零的图表。有限域中的对应条件是非零条件，不使用实数方向符号删根。

原根映射为 `t=2*((v-u)*py-w*(px-u))`、`z=2*c0x-px`、`h=-c0y`、`y=c6y`。通用恒等式、端口因子单位及互补交点分离给出双向局部重建；局部同构固定 `r`，故驻定理想随之保持。整盒残差检查只辅助发现错误。

新系统有独立严格自映和压缩证书，根盒半宽 `10^-50`，压缩常数小于 `3*10^-42`。原根整个像严格包含于新盒；所有必要主元和导数在该盒避零。目标处 `f` 约 `0.39452455`，临界微分乘子约 `4.03686537`，`delta_rF` 约 `-16.51212262`，均以有理区间认证。

## 7. 标量范数的伪临界分支

在两条线中，`gcd(N,N_u,N_v,N_w)` 都仍有计重数 60 次公因子。对全部不可约因子独立检验不可约性并乘回，再于每个剩余域构造 16 维乘法矩阵，共同计算理想 `(F,delta_uF,delta_vF,delta_wF)`：

- 计重数 28 次来自标量公因子，但共同临界商维数实际为零。
- 计重数 20 次来自 `r=0`，不属于目标正半径图表。
- 余下计重数 12 次的候选由 `J1` 或 `delta_rF` 单位条件排除。

因此这些特定参数线上，60 次标量公因子没有留下目标图表允许的共同临界分支。这是固定端口线的诊断，不证明原目标不存在，也不是原最小多项式的次数。

局部化使用有限商代数中必要因子乘积的 16 次稳定像，处理可能存在的幂零部分；没有用原始乘法矩阵秩代替稳定像。`checks.py` 的分裂代数反例验证“分别有零点”不等于“同分支有公零点”，幂零反例验证稳定幂确实必要。
